# YuvaIntern Task 4 — Data Science Tool Mastery Project

## Project
**Iris Dataset Exploration and Classification**

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Jupyter Notebook.

## Work covered
- Dataset loading and inspection
- Data types, descriptive statistics, missing values and duplicates
- NumPy numerical summaries
- Pandas filtering, grouping, aggregation and feature creation
- Bar chart, histogram, scatter plot and correlation heatmap
- Train/test split, StandardScaler and KNN classification
- Accuracy, classification report and confusion matrix
- Findings and conclusion

## How to run
1. Install dependencies with `pip install -r requirements.txt`.
2. Open `Task_4_Data_Science_Tool_Mastery.ipynb` in Jupyter.
3. Run cells from top to bottom.

The dataset is loaded from scikit-learn; no separate CSV download is needed.

Dataset documentation: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html
